# KOZRAGE — сайт услуг

Готовый стартовый проект для публикации на Vercel с отправкой заявок в Telegram.

## Что внутри
- Адаптивный сайт в тёмном стиле KOZRAGE.
- Каталог из пяти услуг и фильтры.
- Корзина и предварительный расчёт суммы.
- Форма заявки.
- Серверный endpoint `/api/order`, который отправляет заявки Telegram-ботом.
- Контактная ссылка на `https://t.me/mynameisraze`.

## 1. Создай Telegram-бота
1. Открой Telegram и найди `@BotFather`.
2. Отправь `/newbot`, задай имя и username бота.
3. Скопируй выданный API token. Не публикуй его и не вставляй в код сайта.
4. Открой чат с новым ботом и нажми Start.
5. Чтобы получить свой chat_id, открой в браузере адрес ниже, подставив токен:
   `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`
6. Найди в ответе `"chat":{"id":...}` — это твой `TELEGRAM_CHAT_ID`.
   Если `getUpdates` пустой, отправь боту любое сообщение и обнови страницу.

## 2. Опубликуй сайт на Vercel
1. Создай аккаунт на https://vercel.com/.
2. Загрузи папку проекта в новый GitHub-репозиторий.
3. В Vercel выбери Add New → Project и импортируй репозиторий.
4. В Project Settings → Environment Variables добавь:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather.
   - `TELEGRAM_CHAT_ID` — твой chat_id.
5. Нажми Deploy. После публикации Vercel выдаст бесплатный адрес вида `имя-проекта.vercel.app`.

## 3. Важно
- Не добавляй токен Telegram в `script.js`, `index.html` или любой публичный файл.
- Если токен случайно стал публичным, отзови его через BotFather и выпусти новый.
- Бесплатный адрес Vercel подходит для первого запуска. Собственный домен можно подключить позже.
- Перед запуском проверь отправку тестовой заявки.
- В форме указано, что пользователь отправляет данные для связи. Перед публичным запуском добавь понятную политику конфиденциальности и укажи, кто обрабатывает заявки.

## Локальный запуск (необязательно)
Установи Node.js и Vercel CLI, затем в папке проекта:
```bash
npm install -g vercel
vercel dev
```
Создай `.env.local` по образцу `.env.example` с настоящими значениями. Не отправляй `.env.local` в GitHub.
